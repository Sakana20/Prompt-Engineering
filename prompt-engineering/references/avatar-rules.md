# 多人物数字人口播 Prompt 规则

根据已通过校验的口播文案生成一段精简、自然、连贯的视频 Prompt。文案是场景、人物
状态、情绪、商品使用方式和表达语气的唯一语义依据。不要复述文案，不生成脚本或分镜。
用于即创或 LibTV 首帧图的 `person_prompt`/`image_prompt` 必须控制在 120–180 个中文字符。

## 账号人物体系

- 22–24 岁中国女生，真实自然、亲和、干净、生活化；
- 长相方向可覆盖甜美、可爱、清冷、御姐、邻家、清爽等年轻主流审美，但不得偏向大妈、阿姨、中年女性、中老年或老气方向；
- 分享日常购物、生活方式和真实消费体验；
- 不是测评人、带货主播、主持人或销售；
- 每条 Prompt 必须使用不同人物和不同服装；
- 批次内主动改变脸型、可见五官特征、发型、发色、长相方向和完整服装组合；
- 服装从主流日常审美中选择并批次去重，可覆盖通勤、休闲、甜酷、简约、轻运动等方向；
- 可使用 T 恤、衬衫、针织、卫衣、西装外套、牛仔外套、连衣裙、半裙、牛仔裤、阔腿裤等完整搭配；
- 人物可以不同，但整体保持年轻、自然、干净、生活化的账号审美；
- 禁止亚洲女生旧口径、网红脸、明星脸、欧美妆、浓妆、夸张饰品、暴露穿搭、土味搭配、大面积服装 logo、塑料皮肤、大妈感、阿姨感和中老年感。

生成前为每条记录简短的 `identity_key` 与 `outfit_key`；两组键在同一批次中都不得重复。
禁止写“同一人物”“相同五官”“固定人物”“保持脸部特征一致”等连续性描述。

若生成 Prompt 包包含“本次筛选的人物学习块”，按
[person-prompt-block-contracts.md](person-prompt-block-contracts.md) 从 identity、hair、outfit、
scene 中选择兼容变量组合。正常生成不得再读取完整人物正式库。learned 块不得重复或覆盖本文件的固定镜头、商品摆放、不手持、
不看不接触商品、logo 和无字幕约束，也不得复刻具体真人。人物身份标签和服装标签集中度只作
预警；批次内 `identity_key`、`outfit_key` 唯一性仍是硬校验。空 learned 资源保持旧行为。

## 场景与商品

- Prompt 开头必须先写 `竖屏9:16，固定中景，手机实拍，数字人口播首帧`，不是生活方式抓拍；
- 优先由文案第一句判断背景场景，整个视频只使用一个符合逻辑的生活背景；
- 场景只作为背景，不驱动人物做准备、收拾、换鞋、低头看桌面、看包或看商品等动作；
- 商品必须位于人物面前的桌面、餐桌、台面或办公桌上，远离人物双手；
- 禁止把商品放在人物身后、背后、背景里、远处、侧后方、沙发、玄关、购物袋或画面边缘；
- 禁止手持商品，不拿起、不递近镜头、不用手持续展示包装；
- 人物不看商品、不接触商品，商品只提供环境信息；
- 仅商品本体或商品包装可以包含商品自带 logo，非商品区域无 logo；
- 商品是生活的一部分，不使用商业广告棚或直播间陈列。

## 表演与镜头

- 面对镜头自然口播，说话时眼睛必须全程直视镜头，保持稳定镜头交流，口型同步，节奏自然；
- 人物必须正脸站定或坐定，身体稳定，不执行场景动作；
- 仅允许自然微笑，不写眨眼、点头、手势、重心变化或其他身体动作；
- 禁止主持、演讲、直播带货动作，禁止夸张动作、频繁挥手和背稿感；
- 竖屏 9:16、固定中景、手机实拍必须位于 Prompt 最前面，不允许放到末尾；固定机位，不允许使用半身景别，人物居中；
- 不切镜、不运镜、不推拉摇移，模拟手机固定拍摄和真实生活 Vlog。

## 画面

真实摄影、手机实拍、生活记录、自然光、暖色调、真实曝光与白平衡、真实肤色、轻微背景
虚化。保留皮肤纹理，不过度磨皮、锐化或美颜。可描述 HDR、8K 和电影级真实摄影，但
整体不得产生商业摆拍或明显 AI 感。
首帧图 Prompt 优先使用“手机实拍、固定中景、竖屏9:16”，不要堆叠 HDR、8K、电影级、
暖色调、真实白平衡等长风格词。

禁止提词器、字幕、文字贴片、贴纸、特效、动漫、二次元、CG、AI 主播、虚拟主播和
明显 AI 生成痕迹。

最终只输出数字人 Prompt 正文，不输出标题、解释、Markdown 或额外提示。
